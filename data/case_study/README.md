# Case-study data

The standardized files here contain 95 monitoring points, 5 selected platforms, and 5 hazardous sources from the supplied combined coordinate file. The manuscript reports 20 candidate platform sites, but the other 15 candidate coordinates were not present in the supplied file and were not fabricated.

The official `run_case_study.py` expects the existing repository's `7Case Study/` folder (including no-fly-zone data and other GIS inputs) to remain in place when this package is overlaid.
